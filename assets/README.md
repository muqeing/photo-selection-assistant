# Application icon source

`app-icon.svg` was created specifically for this project's initial public source export on 2026-09-27 using basic SVG shapes. It replaces the earlier placeholder icon. It contains no external fonts, images, or embedded assets and is covered by the project license.

The desktop files in `src-tauri/icons/` are generated from this SVG using the Tauri CLI:

```sh
pnpm tauri icon assets/app-icon.svg
```
