# 照片筛选助手使用说明

照片筛选助手在本机完成编号确认、照片目录扫描和安全复制。它不会上传源照片，也不会删除或移动源文件。

## 新建筛片会话

1. 在“筛片会话”新建会话，填写能识别本次工作的任务标识（例如订单号或客户简称）。任务标识不能为空。
2. 进入会话后，在“客户选片信息”拖入一张或多张截图，粘贴图片，或直接粘贴文字。也可以手动添加编号。
3. 检查识别出的编号。每个编号都必须由操作员确认；可编辑、删除或新增。确认后才可以扫描，原始显示格式会保留，但匹配会忽略任意前导零。

## 选择目录并扫描

1. 点击“选择源照片目录”。默认目标会设置为源目录同级的 `照片成片/待精修的原片`。
2. 如需放到其他位置，点击“选择目标目录基准”；应用会在所选基准下建立同样的 `照片成片/待精修的原片` 路径。
3. 点击“确认编号并扫描”。扫描会递归查找已启用的 RAW、JPG/JPEG 扩展名，并自动排除目标目录，避免把已复制文件再次当作源文件。

复制到 macOS 已挂载的 SMB/NAS 目录时，界面会提示网络复制规则：应用先独占创建持久未完成标记，再独占创建最终文件，写入并重新打开验证哈希后才清除标记。完成前请勿使用输出文件。断开或取消会留下目标文件和 `.photo-selector-incomplete/<同名文件>` 记录，并阻止自动重试；请改选空目标目录重试，或人工核对后处理目标及同名记录。此规则是 Mac SMB 的实现策略，不表示所有平台都支持原子提交，也不表示真实业务 NAS 场景已经完成验收。

一个完整匹配通常至少包含一个 RAW 和一个 JPG/JPEG。扩展名可在“文件设置”中调整。

## 重号、缺失与冲突

- 同一编号出现多组候选时，应用会暂停并显示候选路径、格式和可预览的图片；请人工选择正确组。
- 只找到部分格式、没有找到编号时，选择接受部分文件或跳过该编号。不会自动猜测。
- 目标中已有同名且内容相同的文件会被安全跳过；若内容不同，复制会暂停，绝不覆盖已有文件。
- 源目录、目标目录断开、权限不足、空间不足或源文件在扫描后变化时，任务会暂停，不会把该项标记为完成。恢复目录后重新检查或重新扫描。

## 复制与完成报告

可在文件设置启用“复制前二次确认”，启用后需确认清单才开始复制；异常仍会强制暂停。复制使用临时文件、完成后校验内容，并保留会话与每个文件的复制/跳过/失败历史。

完成报告会显示已复制数量、内容相同跳过数量、人工跳过数量、失败数量、源/目标目录名称及开始、结束时间。可在“历史记录”重新打开会话查看状态。

## 离线与隐私

默认使用离线 OCR，运行时不需要访问 CDN。截图、粘贴图片和文本仅保存为完成当前会话所需的本机临时输入，任务完成、取消或失败后会清理。源照片始终留在原目录；应用不会把照片上传到云端。

若在“模型设置”启用云端识别，只有导入的识别内容会按所选服务商的配置发送；请在使用前确认服务商条款、网络和费用。云端失败时，可按设置回退离线识别；离线识别仍无法确认时，改为人工录入。
