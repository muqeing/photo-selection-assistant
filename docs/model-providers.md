# 模型服务商配置

云端识别是可选功能；默认是本地离线 OCR。API Key 只写入 macOS Keychain 或 Windows Credential Manager，应用数据库只保存不可用来调用的引用名，切勿把 Key 写入任务备注、截图或仓库。

## 两种 OpenAI 兼容格式

- **Responses**：请求发送到 `/responses`，多模态输入使用 Responses 的 input 结构。它适合已经提供 Responses 兼容接口的服务商。
- **Chat Completions**：请求发送到 `/chat/completions`，多模态输入使用 messages 结构。它适合传统 OpenAI Chat Completions 兼容接口。

“Base URL”填写服务的 API 根地址，应用会补充对应的 `/responses` 或 `/chat/completions` 路径；“完整请求地址”则必须填写包含上述最终路径的 URL，应用不会再拼接。保存前请确认不要把模型名填进 URL。

## 模板与自定义服务

“模型设置”提供阿里、腾讯、火山、小米和自定义模板。模板只预填公开的地址格式、协议和示例模型名；服务商的可用区域、模型名、权限与价格会变化，以该服务商控制台及官方文档为准。

1. 选择模板或“自定义”。
2. 选择 Base URL 或完整请求地址，以及 Responses 或 Chat Completions 格式。
3. 输入模型名；如果没有出现在列表中，可以手动填写服务商已授权的模型名。
4. 输入 API Key，保存后点击“测试连接”。测试成功只表示当前地址、密钥和模型可建立请求，不代表免费或不限额。

阿里百炼、腾讯 TokenHub、火山方舟和小米 MiMo 都可能根据区域或产品线提供不同兼容端点。不要把控制台网页地址当作 API Base URL；应从该服务商当前官方 API 文档复制端点。

## 失败回退与费用

推荐保留“云端失败后自动使用离线识别”。回退顺序是：云端请求失败或超时 → 本地离线 OCR → 操作员手动编辑并确认编号。任何来源的编号都必须人工确认后才能扫描。

真实 API 请求可能产生按调用量、图片或 token 计费的费用，也可能受账户余额、速率限制和内容策略影响。连接测试同样可能产生费用；使用前请确认账户权限与预算。
