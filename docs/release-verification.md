## 合成验收

运行 `pnpm acceptance:fixture`，使用输出的源目录和清单：

1. 创建测试会话，输入 `1234`、`781` 并人工确认。
2. 选择测试源目录，扫描并为 `1234` 选择 RAW+JPG 候选组。
3. 复制后预期 3 个文件复制、1 个相同内容跳过，核对源 SHA-256 不变。
4. 仅在该测试目录制造同名不同内容的目标，重扫后应阻止覆盖。
5. 重开历史记录核对报告，用合成编号图片检验实际界面的离线 OCR。

合成文件不是有效相机 RAW 样片。该流程不能证明预览质量、真实 NAS 断线恢复、权限或磁盘不足的实机行为。
